# C++ Examples

Template repository for making UE4SS C++ mods: [UE4SSCPPTemplate](https://github.com/UE4SS-RE/UE4SSCPPTemplate) — note that C++ mods for the Linux build must be compiled as `.so` files (not `.dll`), targeting Linux with GCC or Clang.

Search GitHub for any C++ code calling reasonably uniquely-named UE4SS API functions, excluding the actual UE4SS repository from the search:
